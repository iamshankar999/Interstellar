# Interstellar (Hack The Box)

This repository contains files related to the Hack The Box "Interstellar" machine.

## Files

- `code.py`: Python script used during the exploitation or enumeration phase.
- `interstellar_attack_commands.sh`: A shell script containing the list of commands used during the attack.

## Usage

These files were created and tested in a controlled HTB environment for educational purposes only.

## Tools Used

- Python 3.x
- Bash
- Nmap, Netcat, and standard Linux utilities
